# ELT SIM UI update

The admin navigation has been consolidated to six primary menu items:

1. Dashboard
2. Registrations
3. SIM Center
   - SIM Management
   - Import SIM
   - File History
4. People & Access
   - Users
   - Agents
   - Customers
5. Reports
6. Settings
   - My Profile
   - System
   - Audit Logs

Packages are no longer shown as a separate menu/module. Package data remains attached to SIM records in the backend/database so the registration flow can read the package assigned to a SIM automatically.

Payments are no longer shown in the admin navigation or frontend route.

Customer registration remains registration-focused: choose SIM, upload passport/OCR, confirm information, and submit. There is no OTP step.
